# 🛒 BazarDor (বাজার দর)

**BazarDor** is a modern, responsive, and localized web application designed to help users and households track daily market prices, analyze commodity price fluctuations, and monitor category-wise market dynamics efficiently.

---

## 🛠️ Technologies Used

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling & UI:** Tailwind CSS, DaisyUI, HeroUI (React Aria)
- **Icons:** Lucide React, Font Awesome, React Icons
- **Authentication:** Better Auth
- **State Management & React Hooks:** Context API, React Hooks (`useState`, `useEffect`)

---

## ✨ Key Features

1. **📊 Real-time Commodity Price Tracking:**
   - Visual indicators for price fluctuations (`PriceUp` & `PriceDown`) alongside daily updated market rates for everyday groceries and essential goods.

2. **🏷️ Dynamic Category Filtering & Empty State:**
   - Seamless product filtering by categories, paired with a custom, user-friendly "Empty State" component when no items are available in a category.

3. **👤 User Profile Management & Dedicated Update Route:**
   - Complete user profile overview with a dedicated profile update route (`/profile/update`) for managing account information securely.

4. **🇧🇩 Fully Localized Bengali UI/UX:**
   - Clean, culturally tailored Bengali interface utilizing modern typography (Plus Jakarta Sans / Hind Siliguri) for optimal readability and accessibility.

5. **📱 Responsive Layout & Smooth Authentication:**
   - Fully responsive layout across Mobile, Tablet, and Desktop platforms, integrated with an optimized authentication flow to eliminate layout flashes during auth redirects.

---

## 🚀 Getting Started

First, clone the repository and install the dependencies:

```bash
git clone <your-repository-url>
cd bazardor
npm install
npm run dev
```
